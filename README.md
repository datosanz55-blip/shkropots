# ShkrobotS — лендинг

Одностраничный сайт для ShkrobotS Loft Studio
(лофт-мебель и мягкая мебель на заказ, Челябинск).

## Структура

```
index.html            — лендинг
catalog.html          — страница каталога
styles.css            — общие стили обеих страниц
catalog-data.js       — ЕДИНСТВЕННОЕ место наполнения каталога
catalog.js            — фильтр, отрисовка, лайтбокс каталога
images/
  logo.jpg            — логотип (белая графика на тёмном фоне)
  favicon.svg         — иконка вкладки
  metal.jpg           — текстура тёмного металла (фон страницы)
  wood.jpg            — текстура массива дерева (акцентные секции)
  stone.jpg, rust.jpg — не используются, остались от прежних вариантов
  catalog/            — фото каталога (до 1600 px)
  catalog/thumb/      — превью для сетки (до 700 px)
  terrace-pool.jpg    — фото выполненной работы
  gazebo-tent.jpg     — фото выполненной работы
  terrace-balcony.jpg — фото выполненной работы
Dockerfile            — образ nginx со статикой
nginx.conf            — конфиг nginx (gzip, кеш, security-заголовки)
docker-compose.yml    — вариант запуска через Compose
```

## Локальный запуск

Просто открой `index.html` в браузере — сборка не нужна.

Проверить именно в контейнере (как на проде):

```bash
docker build -t shkropots-web .
docker run --rm -p 8080:80 shkropots-web
# открыть http://localhost:8080
```

Или через Compose:

```bash
docker compose up --build
# открыть http://localhost:8080
```

## Деплой через Dokploy

Сервер (по SSH через Termius) должен иметь установленный Dokploy.

Вариант A — **Application (Dockerfile)** (рекомендуется):

1. В Dokploy создай проект → **Create Service** → **Application**.
2. Source: подключи этот Git-репозиторий и ветку.
3. Build Type: **Dockerfile**, путь — `Dockerfile`.
4. В разделе **Domains** добавь домен, Container Port — `80`, включи HTTPS (Let's Encrypt).
5. **Deploy**. Dokploy соберёт образ по `Dockerfile` и поднимет контейнер за встроенным Traefik.

Вариант B — **Compose**:

1. Create Service → **Compose**, подключи репозиторий.
2. Compose Path — `docker-compose.yml`.
3. Домен вешается на сервис `web`, порт `80`.

## Стек

Чистый HTML/CSS/JS, без зависимостей и фреймворков. Шрифты — Google Fonts
(Jost, Manrope) через CDN.

## Что внутри

- Логотип в шапке (JPEG без прозрачности, фон снимается `mix-blend-mode:screen`)
- Бургер-меню на мобильных (закрывается по Escape, по клику на пункт и на десктопе)
- SEO: description, Open Graph, favicon, микроразметка FurnitureStore (JSON-LD)
- Тёмный металл фоном, массив дерева — на акцентных секциях
  (обе текстуры заданы переменными --tex-bg / --tex-accent, менять в одном месте)
- Каталог на отдельной странице: 21 категория, фильтр, адреса вида
  `catalog.html#beds`, ленивая загрузка фото, лайтбокс
- Блоки «О компании», «Отзывы» и «Новости»
- Полоса-манифест с тремя ключевыми утверждениями бренда
- Hero-карусель из трёх фото работ (стрелки, точки, свайп, автоплей)
- Калькулятор примерной стоимости изделия
- Лайтбокс для просмотра фото
- Scroll-reveal анимации, параллакс на hero
- Форма заявки (сейчас без бэкенда — только визуальный отклик)

## Заметки на будущее

- **Домен**: в `<head>` в `canonical` и Open Graph стоит заглушка `https://shkrobots.ru/`.
  После подключения домена в Dokploy заменить на реальный — иначе превью
  ссылки в мессенджерах и canonical будут указывать не туда.
- **Отзывы — заглушки.** Реальная в блоке только сводка рейтинга (5,0 при 8 оценках).
  Три карточки нужно заполнить дословными отзывами с Я.Карт либо подключить
  виджет Яндекса по ID организации. Выдуманные отзывы не размещать —
  это нарушает правила поисковиков и вводит клиентов в заблуждение.
- **Новости — заглушки**: заголовки, тексты, даты и фото подставить от клиента.
- **Каталог: 103 позиции в 8 категориях из 21.** Заполнены: мебель для офиса (41),
  уличная мебель (42), столы журнальные (7), шкафы (4), стеллажи (3),
  гардеробные (2), тумбы под ТВ (2), перегородки (2).
  Остальные 13 категорий пока показаны заглушками.
  Наполнение: фото в `images/catalog/` (крупное) и `images/catalog/thumb/`
  (превью), запись в `CATALOG_ITEMS` внутри `catalog-data.js` — HTML не трогать.
  Когда заполнятся все категории, выставить `CATALOG_PLACEHOLDERS_PER_CATEGORY = 0`.
- Обработка присланных фото: длинная сторона 1600 px (лайтбокс) и 700 px (сетка),
  JPEG q82/q78, progressive, EXIF-поворот учтён, метаданные вырезаны.
  Апскейл не делаем — если исходник меньше, он сохраняется как есть.
- **ВАЖНО, партия «Уличная мебель» (75 файлов).** 28 из них — не фотографии,
  а AI-рендеры: нумерованная серия `001–015` (2400x1792 и 4800x3584 — ровно
  двукратный апскейл), файл `97c9c8bb_gemini.png` и 13 скриншот-копий тех же
  сцен. В каталог они НЕ включены: на них мебель, которую не изготавливали,
  включая лофт-кухню и тумбу под ТВ (в папке «Уличная мебель»). Размещать
  их как выполненные работы нельзя — клиент закажет то, чего не существует.
  Если заказчик хочет их показать, нужен отдельный блок «Концепты /
  визуализации» с явной подписью. Ещё у двух файлов (`03а.jpeg`, `11а.jpeg`)
  в EXIF стоит `Software: Problembo.com` — это реальные фото, прошедшие
  через AI-апскейл; они оставлены.
- Из 47 реальных файлов партии отобрано 39: сняты дубли (один сюжет в
  нескольких кропах), монтажный кадр с человеком и упаковкой, кадр с

- В списке категорий от клиента были дубли: «гардеробные лофт»/«гардеробные»

- **Фото категорий не присланы.** Секция «Наши изделия» — сетка из 6 плиток
