# ShkrobotS — лендинг

Одностраничный сайт для ShkrobotS Loft Studio
(лофт-мебель и мягкая мебель на заказ, Челябинск).

## Структура

```
index.html            — вся разметка, стили и JS в одном файле
images/
  logo.jpg            — логотип (белая графика на тёмном фоне)
  favicon.svg         — иконка вкладки
  stone.jpg           — текстура тёмного камня (фон страницы)
  wood.jpg            — текстура массива дерева (акцентные секции)
  terrace-pool.jpg    — фото выполненной работы
  gazebo-tent.jpg     — фото выполненной работы
  terrace-balcony.jpg — фото выполненной работы
Dockerfile            — образ nginx со статикой
nginx.conf            — конфиг nginx (gzip, кеш, security-заголовки)
docker-compose.yml    — вариант запуска через Compose
```

## Локальный запуск

Просто открой `index.html` в браузере — сборка не нужна.

Проверить именно в контейнере (как на проде):

```bash
docker build -t shkropots-web .
docker run --rm -p 8080:80 shkropots-web
# открыть http://localhost:8080
```

Или через Compose:

```bash
docker compose up --build
# открыть http://localhost:8080
```

## Деплой через Dokploy

Сервер (по SSH через Termius) должен иметь установленный Dokploy.

Вариант A — **Application (Dockerfile)** (рекомендуется):

1. В Dokploy создай проект → **Create Service** → **Application**.
2. Source: подключи этот Git-репозиторий и ветку.
3. Build Type: **Dockerfile**, путь — `Dockerfile`.
4. В разделе **Domains** добавь домен, Container Port — `80`, включи HTTPS (Let's Encrypt).
5. **Deploy**. Dokploy соберёт образ по `Dockerfile` и поднимет контейнер за встроенным Traefik.

Вариант B — **Compose**:

1. Create Service → **Compose**, подключи репозиторий.
2. Compose Path — `docker-compose.yml`.
3. Домен вешается на сервис `web`, порт `80`.

## Стек

Чистый HTML/CSS/JS, без зависимостей и фреймворков. Шрифты — Google Fonts
(Jost, Manrope) через CDN.

## Что внутри

- Логотип в шапке (JPEG без прозрачности, фон снимается `mix-blend-mode:screen`)
- Бургер-меню на мобильных (закрывается по Escape, по клику на пункт и на десктопе)
- SEO: description, Open Graph, favicon, микроразметка FurnitureStore (JSON-LD)
- Тёмный камень фоном, массив дерева — на акцентных секциях
- Hero-карусель из трёх фото работ (стрелки, точки, свайп, автоплей)
- Калькулятор примерной стоимости изделия
- Лайтбокс для просмотра фото
- Scroll-reveal анимации, параллакс на hero
- Форма заявки (сейчас без бэкенда — только визуальный отклик)

## Заметки на будущее

- **Домен**: в `<head>` в `canonical` и Open Graph стоит заглушка `https://shkrobots.ru/`.
  После подключения домена в Dokploy заменить на реальный — иначе превью
  ссылки в мессенджерах и canonical будут указывать не туда.
- **Цены в калькуляторе — плейсхолдеры**, подтвердить у клиента.
- **Фото категорий не присланы.** Секция «Наши изделия» — сетка из 6 плиток
  (Столы, Стеллажи, Кровати, Консоли, Мягкая мебель, Рабочие зоны); пока они
  показаны текстурными заглушками. Положить файлы в `images/` под именами
  `cat-tables.jpg`, `cat-shelving.jpg`, `cat-beds.jpg`, `cat-consoles.jpg`,
  `cat-soft.jpg`, `cat-desks.jpg` — плитка сама станет кликабельной с лайтбоксом.
- **Фото работ** пока с прошлого профиля (терраса, беседка) — заменить на лофт-мебель.
- **Email, WhatsApp, каталог PDF** — ждём значения от клиента, ссылок в коде пока нет.
- **Логотип** — JPEG; при получении PNG/SVG с прозрачностью убрать `mix-blend-mode`.
- `stone.jpg` ~518 КБ — при желании можно пережать для ускорения загрузки.
- Форма заявки пока без бэкенда — нужен обработчик (Telegram-бот / почта / CRM).
- Шрифты грузятся с Google Fonts CDN. Если на сервере будут перебои с доступом
  к CDN — стоит перейти на self-hosted шрифты.
- Иконки соцсетей/карт в футере ведут на `#` — заменить на реальные ссылки.
